CostControl funciona 100 % en local con su motor determinista. La IA es opcional y añade comprensión de frases más libres («la mitad para el primero y el resto según las horas»). Para activarla:

  1. Consigue una clave de API de Anthropic en console.anthropic.com.
  2. Define la variable de entorno antes de arrancar la app:
    ANTHROPIC_API_KEY = tu-clave
  3. (Opcional) COSTCONTROL_AI_MODE = auto (por defecto) o siempre, y COSTCONTROL_AI_MODEL = claude-haiku-4-5.
  4. Reinicia CostControl. Verás el distintivo ✨ IA activa en la pantalla de reparto.
{% endif %}
Privacidad
  • Sin clave de API, nada sale de tu equipo: el motor local resuelve todo.
  • Con la IA activa, solo se envía a Anthropic el texto del reparto y la lista de códigos/nombres de proyecto para traducir la frase. No se envían importes de documentos, terceros ni la base de datos.
  • En modo auto la IA solo se llama cuando el motor local no entiende la frase, minimizando lo que se envía.
